# Bad Piggies :: Rebooted Edition
Community-driven Moddification of the game Bad Piggies!
Thanks to Miuna for all the prior work from the mod called BPLE, we really hope you had more time to spare for your project.

## Changes:
- Added mega monster wheels (Large Off Road Wheel)
- change large off road wheel part tier to regular
- Remove prop panel
- add second apbb
- Extend spring length of second apbb by factor of 2
- Music Button (good this time)
- remove zoom limit
- Large Exploding Grappling Hook (Rapid Fire Gun)
- add monster sticky wheels
- more alien engines
- grand tnt (has engine power)
- bread.
- larger off road wheel
- alien wooden frame (flexible)
- invert alien plane propeller direction (now it points forward like the rest of the propellers)
- reverse wheel
- New fancy part button UI
- Water texture
- Changed version selection screen
- Better camera-pig follow buttons

## Known issues:
